# 에펙 립싱크 적용 가이드 (입 모양 교체 + 오디오 연동)

## 파일 구성 (캐릭터별, 모두 같은 크기의 투명 PNG)

| 파일 | 용도 |
|---|---|
| `client_body_nomouth.png` / `architect_body_nomouth.png` | 입을 지운 캐릭터 본체 |
| `*_mouth_0_closed.png` | 다문 입 (무음) |
| `*_mouth_1_small.png` | 조금 벌린 입 (작은 소리) |
| `*_mouth_2_wide.png` | 크게 벌린 입 (큰 소리) |
| `*_mouth_3_o.png` | 동그란 입 ("오/우", 놀람) — 수동으로 키프레임 |

본체와 입 PNG는 **캔버스 크기와 위치가 같다.** 같은 좌표에 겹쳐 올리면 입 위치가 자동으로 맞는다.

## 1. 캐릭터 프리컴프 만들기 (캐릭터마다)

1. 본체 PNG와 입 PNG 4장을 한 컴포지션에 넣고 **모두 같은 위치(가운데 정렬)**에 둔다.
2. 레이어 순서: 위에서부터 `mouth_0` ~ `mouth_3`, 맨 아래 `body`.
3. 이 컴포지션을 메인 컴포지션에 넣고, 위치·크기는 프리컴프 단위로 조절한다.

## 2. 오디오를 키프레임으로 변환 (캐릭터마다 따로)

1. 그 캐릭터의 대사 MP3만 들어 있는 컴포지션을 만든다(예: `VO_건축사`). 다른 캐릭터 음성이 섞이면 안 된다.
2. 메뉴 **Animation → Keyframe Assistant → Convert Audio to Keyframes** 실행.
3. `Audio Amplitude` 레이어가 생기면 이름을 `AMP_건축사`처럼 바꾼다.
4. 이 레이어를 캐릭터 프리컴프 안으로 복사한다(또는 표현식에서 `comp("VO_건축사").layer(...)`로 참조).
5. `Both Channels > Slider` 값을 재생하며 확인한다. 무음일 때 값, 말할 때 최댓값을 메모한다.

## 3. 입 레이어 불투명도(Opacity) 표현식

각 입 레이어의 **Opacity**에 Alt(Option)+클릭으로 아래를 붙여 넣고, `me` 값만 레이어마다 바꾼다.

```js
// me: 이 레이어의 입 번호 (closed=0, small=1, wide=2)
var me = 0;
posterizeTime(12);                       // 초당 12번만 입 모양 변경 (카툰 느낌)
var a = thisComp.layer("AMP_건축사").effect("Both Channels")("Slider").value;
var lo = 4;                              // 이 값보다 작으면 다문 입
var hi = 14;                             // 이 값보다 크면 크게 벌린 입
var lvl = (a < lo) ? 0 : (a < hi ? 1 : 2);
(lvl == me) ? 100 : 0;
```

- `mouth_0_closed` → `me = 0`, `mouth_1_small` → `me = 1`, `mouth_2_wide` → `me = 2`
- `lo`, `hi`는 2단계에서 본 Slider 값에 맞춰 조정한다.
  - 입이 너무 자주 크게 벌어지면 `hi`를 올린다.
  - 말하는 중에 입이 자주 닫히면 `lo`를 내린다.
- `mouth_3_o`는 표현식 없이 불투명도 0으로 두고, "네?", "오" 같은 순간에만 키프레임으로 켠다. 켤 때는 다른 입 레이어를 잠깐 가린다.

## 4. 더 자연스럽게 만드는 팁

- **숨쉬기**: 본체 프리컴프 Scale Y에 `[100, 100 + Math.sin(time*2)*0.6]` (아주 미세하게)
- **말할 때 몸 흔들림**: Rotation에 `wiggle(2, 0.6)`을 대사 구간에만 적용
- **눈 깜빡임**: 눈을 감은 상태의 본체 PNG가 있으면 2~4초마다 2프레임씩 교체
- 입 모양 변경은 12fps, 몸 움직임은 24/30fps로 두면 카툰 느낌이 산다.
