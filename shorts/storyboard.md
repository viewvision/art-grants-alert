## v2 → v3 바뀐 점

- 2번: 클라이언트 대사 변경(위치·임대료), **리모델링 상상 장면이 5번에서 2번으로 이동**
- 3번: "보" → **"기둥"**, 배경 사진이 여러 장으로 바뀌는 점검 연출
- 4번: 건축사 대사 변경, 점선이 기둥 + 보
- 5번: 새 대사, **구조보강 장면 대신 리모델링 이미지 붕괴**
- 6번: 구조보강 대사가 외부 장면으로 이동, 자막에 [안전과 비용] 추가
- 7번: "속까지" 추가 / 8번: 엔딩 문구 "건물을 살 때도"
- 삭제: 클라이언트 "그럼 리모델링하면 되지 않나요?"
